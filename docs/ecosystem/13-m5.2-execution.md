## 4. 关键判断

- **不放宽 ±8 pulse 容差来“通过”夹爪。** 三次尝试：170→183、194→207、
  640→620/619；两个方向都提前停住。
- 这不是解析/映射错误，而是夹爪机械卡滞/传动或装配问题；必须人工检查
  开/闭限位、连杆与伺服 horn。
- 内侧目标 194 仍差 13，说明不能靠调整目标或放宽容差解决；停止反复驱动。
- 下一次夹爪测试前必须完成机械维护，确认实际安全端点，再重新授权。
- 停止传播 ≤100 ms、停止安全节点后拒绝新命令尚未实机验证；M5.2 未完成。
- 任何下一次实机动作需要新的明确授权。
