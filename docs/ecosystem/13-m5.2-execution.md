## 4. 关键判断

- **不放宽 ±8 pulse 容差来“通过”夹爪。** 开目标 170 实际 183；
  闭目标 640 实际 620/619；实际可达行程约 183–619。
- 这不是解析/映射错误，而是夹爪机械行程变窄：开/闭限位、连杆卡滞或
  伺服 horn/装配问题；必须人工检查。
- 下一次夹爪测试前必须确认实际安全端点，再定义 open/close 目标；
  不能用“卡滞点”直接当目标反复驱动。
- 停止传播 ≤100 ms、停止安全节点后拒绝新命令尚未实机验证；M5.2 未完成。
- 任何下一次实机动作需要新的明确授权。
